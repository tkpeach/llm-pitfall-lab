# Qwen3.5 数值对照开发工具

本目录提供开发与运行诊断能力：对显式输入执行原生/参考前向，观测中间张量和状态，比较数值与分块漂移，输出报告。工具不是测试用例，不导入 `tests/`，也不由正式 C++ 推理路径隐式调用。

| 文件 | 职责 |
| --- | --- |
| [compare.py](compare.py) | 接受 `--input` 文本消息 JSON，组织资源预检、独立进程、三种分块方式及数值报告 |
| [reference.py](reference.py) | 固定 MLX-LM 参考执行和逐层观测，独立进程运行 |
| [probe.cpp](probe.cpp) | 调用正式 C++ 模型执行输入并导出中间张量、混合状态及短生成 |
| [process.py](process.py) | 有限超时的进程执行与失败时终止、回收 |

输入 JSON 包含非空 `messages` 列表，每项提供字符串 `role` 和 `content`；当前只接受无 padding 的短文本请求。原生探针的输入上限为 128 个渲染后 token。工具检查模型数值正确性，输出中的 passed/failed 是本次输入的诊断结论，不自动等于仓库全部设计目标已验收。

探针 `lab_qwen35_probe` 在 `BUILD_TESTING=OFF` 时仍构建。当前构建和调用命令、容差与参考身份统一见 [数值对照说明](../../../docs/model-validation.md#独立进程数值对照)。固定输入的验收测试位于 [test_qwen35_comparison.py](../../../tests/model/test_qwen35_comparison.py)：测试调用工具，核对场景、覆盖范围、判据与输出；不会在测试中重新实现对照算法。

参考 worker 退出后才启动原生 worker，异常时终止并回收子进程；大张量临时产物在退出作用域时清理，小型报告保存在调用者指定的位置。运行前仍须满足项目资源规则。工具可在开发过程中反复使用，不能把对某一短输入的结果推广为长上下文、任务效果或训练梯度均正确。
