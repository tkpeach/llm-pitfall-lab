## 把概念连在一起

```text
任务需要什么输入和输出
  → 决定需要哪些编码器、主干和输出组件
  → 用配置、模型代码和权重索引核对完整计算路径
  → 将源权重适配为运行框架需要的表示
  → 若量化，明确其近似与存储约定
  → 若后训练，另选训练目标和可更新参数
  → 分别验证前向、状态、梯度、更新和恢复
```

这里有三组不能混用的判断：参数能按名字筛选，不说明任意层可删；权重格式转换通过，不说明任务效果不变；前向一致，不说明训练反向或新进程恢复已正确。Qwen 专题给出前两组的具体例子，数值对照与 LoRA 笔记解释后一组。
