# 项目文档总入口

本文件是 `docs/` 的唯一总入口，负责按需导航和目录职责说明。仓库首页是 [根 README](../README.md)，协作约束见 [AGENTS.md](../AGENTS.md)。新对话接手项目时，从这三个入口读取当前仓库，不依赖之前的聊天记录推断项目结构或决策。

## 阅读顺序与内容归属

先读取根 `AGENTS.md` 和本文件，再读仓库现状；其余文档按任务选择，涉及跨模块变更时扩展阅读相关规范。

接手或快速熟悉仓库时，接着读取 [仓库现状](status.md)，核对当前能力、代码入口、证据和下一步；复习已学内容与复现问题从 [学习记录](../learning/README.md) 进入。模型讨论的通用机制、Qwen 专题与训练/验证实践由 [模型知识导读](../learning/topics/model-knowledge-guide.md) 串联。

| 序号 | 文档 | 负责回答的问题 |

## 项目目录职责

| 位置 | 职责与使用边界 |
| --- | --- |
| 根 `README.md` | 项目目标、范围、实现方式、基本使用和文档入口 |
| 根 `AGENTS.md` | 长期工程原则、学习实践方式及接手项目的必读指引 |
| `docs/` | 当前有效的需求、约束、实现约定、任务规范和设计；不放选型讨论过程 |
| `configs/` | 正式机器可读配置；当前 `resources.toml` 定义磁盘规则，文件存在不代表保护已实现 |
| `fixtures/` | 小型可审查合成样例；契约样例与候选评估种子分开，数据状态及复核要求见任务规范 |
| `src/` | 正式 C++ 模块与共享文件原语；包含计算、任务、资源、检查点、训练运行控制和固定目标语言模型；入口与模块 `CMakeLists.txt` 管理目标和依赖；不依赖旧原型 |
| `tools/model_artifacts/` | 显式模型制品工具；[Qwen3.5 工具入口](../tools/model_artifacts/qwen35/README.md) 维护下载、转换规则、完整性审计与复现比较，不被正式 C++ 运行调用 |
| `tools/numerical_validation/` | [Qwen3.5 数值对照入口](../tools/numerical_validation/qwen35/README.md) 维护开发/运行诊断所需的参考执行、原生观测和对照报告；不依赖测试，关闭测试仍可构建原生探针 |
| `tests/` | 仅维护仓库设计目标的契约、集成与验收测试，以及仓库检查器；测试可调用制品或数值对照工具，但不拥有这些能力的实现；`CMakeLists.txt` 集中注册测试 |
| 根 `CMakeLists.txt`、`cmake/` | C++23 构建、SDK 集成和构建时信息 |
| `cmake/mlx/` | MLX 构建集成与 SDK 定位、版本及必要文件校验；不承担模型执行 |
| `third_party/` | 固定版本的原生依赖及其来源、许可证与校验信息；当前包括 JSON、TOML 库及混合精度 GDN 内核的来源与许可 |
| `docs/status.md` | 当前实现、验证边界、代码入口与下一步；逐项审查证据是否足以支持状态结论 |
| `evidence/current.json` | 唯一当前验收快照，记录代码身份、环境、命令和检查结果；覆盖更新，历史由 Git 管理 |
| `learning/` | 面向用户的主题知识笔记，主要总结提问与讨论；仅收录有分量的真实问题案例，不记录 agent 操作流水 |
| 根 `pyproject.toml`、`uv.lock`、`.python-version` | MLX C++ SDK 供应与 Python 辅助工具环境，不是正式 Python 应用 |
| `.venv/`、`.cache/` | 本机环境和缓存，不提交 Git，占用计入项目预算 |
| `research/` | 历史调研、有限机制验证及旧原型；正式运行不得导入代码、读取运行时配置或隐式依赖其环境 |
| `runs/` | 本机构建文件、实验输入输出、报告与检查点，不提交 Git，占用计入项目预算 |

参考资料按用途分别存放：

- [模型选型归档](../research/model-selection/README.md)：候选评估和模型可行性探测。
- [C++ / MLX 机制验证](../research/cpp-feasibility/README.md)：原生计算、梯度、状态恢复等实验和证据。
- [旧 Python 原型](../research/python-prototype/README.md)：仅供阅读与局部对照，不是第二套正式实现。

历史实验可显式复现，但其结论不能自动计入正式 C++ 模块或完整目标模型的验收。

## 按需维护

入口保持简洁，详细规则只在对应专题维护；改变目录或文档归属时更新本索引。进行代码或验收变更时读取 [维护约定](maintenance.md)，整理学习内容时读取 [学习记录约定](../learning/README.md)。
