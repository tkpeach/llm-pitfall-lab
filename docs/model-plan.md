# 已确认模型与分期路线

相关历史与取舍见 [决策记录](../decisions/0001-model-phases.md)；当前要求以本文件为准。

本文件定义模型身份与迁移边界。范围验收见 [学习规格](learning-spec.md)，研究资料不参与正式运行时加载。

## 固定目标

| 阶段 | 模型 | 目标 |
| --- | --- | --- |
| 一期 | `Qwen/Qwen3.5-4B` | 完整完成推理、后训练、诊断优化、部署与可解释性观察 |
| 二期 | `Qwen/Qwen3.5-9B` | 同硬件迁移，重建基线，验证代表性方法与资源适配 |
| 第三阶段 | MoE 专题对象另定，其他专题按需选定 | 多请求调度、离线偏好优化、MoE 真实推理观察及后训练 |

固定硬件为当前 Apple M4 / 24 GiB Mac。仅运行、训练和观察语言部分，不开展视觉流程或大规模分布式执行。每阶段固定活动目标，不构建任意模型兼容体系。

## 迁移与验收边界

- 复用数据处理、实验与观察方法；不直接迁移 adapter、优化器状态或缓存。
- 每个模型分别比较自身基线与优化结果，不把模型规模变化计为优化收益。
- 二期以真实运行核对资源预测；无法满足约束的项目明确记录并作范围决策，不把边界分析写成完整训练能力已实现。
- 磁盘、时间、暂停释放与恢复要求见 [资源规则](resource-policy.md)，学习范围与完成标准见 [学习规格](learning-spec.md)。

## 已知验证重点

正式短验证需覆盖混合 KV/递推状态的正确性、递推反向内存、量化 LoRA 与重载、在线强化学习成本及观察工具适配。通用推测解码、MTP 等不能仅凭模型特性说明认定当前执行路径已支持。

已有调研结果只能帮助制定验证计划，不替代正式模型基线与验收。
