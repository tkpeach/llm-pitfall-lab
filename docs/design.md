# 一期最小设计与验证关口

本文件规定一期 C++ 实现的模块边界与最小链路关口。语言、计算扩展层、SDK 和配置职责见 [实现约定](implementation.md)，当前实现状态见 [文档总入口](README.md)。

## 边界与数据流

```text
CLI → 配置加载与资源预检 → 任务数据/评估
              → 运行控制 → 模型执行/训练步骤
                         → 完整检查点 → 显式恢复
                         → 小型观察与实验报告
```

- `task`：严格输出契约与评分；不承担模型推理或修复答案。
- `data`：数据版本、划分、tokenization、模板、labels/mask 和消费进度；与模型计算及评分分离。
- `resources`：物理占用去重、卷空闲检查、预计新增峰值预检。纳入归档与受管外部目录；不自动删除、不修改系统设置。
- `checkpoint`：原子提交、完整性及配置身份校验；运行状态不能静默跨配置恢复。
- `runner`：单写入进程锁、暂停请求、步边界保存与退出。暂停后由用户显式恢复；不挂起仍占内存的进程。
- `mechanism`：小型 MLX 优化实验验证真实 optimizer/RNG/数据顺序的恢复。它只验收基础设施，不是 4B 微调，也不作为模型失败后的兜底。
- `model`：固定 Qwen 加载、生成、混合状态和 LoRA 执行；观察在独立运行中采样，不替代主执行路径。不预先实现服务调度或多模型插件。
- `compute`：集中接入专用计算和 Metal 扩展，维护输入输出、状态及梯度契约；不重封装整个 MLX。
- 观察与报告在相应边界采集，绑定模型、代码与配置身份；性能采集与带详细观察的运行分开，不要求搭建通用监控平台。

## 首轮关口

| 关口 | 产物与通过条件 |
| --- | --- |
| D0 正式构建与一致性入口 | CMake 明确使用 C++23，显式定位固定 MLX SDK，验证实际使用的标准库特性；建立本地检查与 CTest，检查文档导航和依赖锁；正式目标不依赖 research 的代码或运行时配置 |
| D1 任务契约 | schema、标注规则、手写样例、严格评估及错误用例 |
| D2 资源与检查点 | 加载和校验统一资源配置；验证额度、硬链接去重、并发预算和超限拒绝；检查点完整性、身份错误拒绝与原子提交 |
| D3 安全控制机制实验 | 独立进程中连续训练对比暂停/恢复；参数、optimizer、随机、数据进度对齐，退出后工作进程结束 |
| D4 目标模型短验证 | 预检后下载明确 revision 的单个执行产物，核验模板、短生成、KV/递推状态、资源与时间；不能将 D3 代替 D4 |
| D5 训练与恢复 | 目标模型 LoRA 更新、检查点与新进程恢复，之后再安排长训练/RL |

每一关口同时要求正式代码通过行为验证、文档与行为一致、证据可追踪、docs/README.md 的实施位置已更新。参考实验不直接计入正式关口；检查随模块就绪接入，不在 D0 要求实现 D2 的资源逻辑。一致性流程见 [文档总入口](README.md#代码与文档的一致性)。

D0–D5 仅覆盖正式最小链路，不等于一期全部完成。后续推理优化、独立效果评估、受控在线强化学习、可解释性和部署仍按 [学习规格](learning-spec.md) 验收。

检查点采用 JSON 控制状态、tensor 文件与校验清单，按格式版本组织；模型、adapter 和优化器张量不展开为 JSON 数组。采用新目录写完并校验后提交，读者只接受完整检查点。

## 控制与正确性

- 正常运行是唯一主路径；`resume` 必须存在有效状态，否则报错。小实验、真实模型与结果明确区分。
- SFT 的安全边界是完整 optimizer 更新，RL 按完整迭代或明确定义的可恢复子边界处理；评估按样例或小批次保存。未提交工作可重做，不重复已提交更新；梯度累积/RL 必须保存其必要状态，不能沿用不完整快照。
- 暂停请求可以来自控制命令或中断信号；请求仅设置标志，工作步骤结束后保存并退出。记录请求到退出延迟，不能承诺正在执行的 GPU kernel 即刻停止。
- 同一运行目录只允许一个 worker。保存前估算新旧状态与临时文件的峰值；原子保存保留最近有效状态，不以半写文件冒充有效状态。
- 完整恢复对照优先于额外测试数量；资源与文件格式错误需明确失败。不能因为单次 loss 下降而宣布模型能力提升。

资源预检不是系统磁盘配额。其他应用可能并发写入，库可能有未估算缓冲；大文件操作必须列清单、留余量、分段复核。系统空间不足且没有保存余量时应在开始前拒绝，不等到临界才写大检查点。

## 当前不实现

一期不实现生产服务、GUI、分布式训练、自动后台调度、通用模型适配及第三阶段专题。MoE 真实推理观察和后训练统一在第三阶段开展。
